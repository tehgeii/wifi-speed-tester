Cek kecepatan. Ukur ping. Pahami koneksimu.

Aplikasi kecil untuk Windows yang bukan cuma menampilkan angka, tapi juga menjelaskan artinya: cocok untuk game atau tidak, kuat untuk Netflix 4K atau tidak, dan kalau lambat, masalahnya di Wi-Fi, router, atau ISP.

⬇ Download untuk Windows Windows on ARM

Gratis · Portable, tanpa install · Windows 10 dan 11

Semua yang perlu kamu tahu tentang koneksimu

⚡ Tes lengkap

Download, upload, ping, jitter, packet loss, dan ping saat sibuk (bufferbloat), dengan gauge dan grafik langsung.

✅ Cocok untuk apa?

Browsing, YouTube 1080p, Netflix 4K, video call, game online, live streaming, dan perkiraan lama download game 50 GB. Terisi selama tes berjalan.

🩺 Diagnosa otomatis

Tes di posisi sekarang, dekat router, lalu pakai kabel. Aplikasi menyimpulkan masalahnya di jangkauan Wi-Fi, Wi-Fi-nya, router, atau ISP.

📡 Pencari sinyal Wi-Fi

Sinyal diperbarui tiap detik, dengan bunyi seperti detektor logam. Simpan titik-titik di rumah untuk menemukan posisi terbaik.

🗺️ Ping ke region

Latensi ke Jakarta, Singapura, Tokyo, dan region lain. Langsung kelihatan cocok atau tidak untuk server game Asia Tenggara.

🎮 Nilai A+ sampai F

Nilai bufferbloat seperti di situs tes untuk gamer: seberapa naik ping saat koneksi dipakai banyak.

📱 Pintar di hotspot HP

Hotspot HP dikenali otomatis, dengan saran khusus HP (posisi HP, 5 GHz, USB tethering) dan mode hemat kuota: penghitung kuota langsung dan total per bulan.

📊 Dibanding tes sebelumnya

Tiap hasil langsung dibandingkan dengan tes terakhir di koneksi yang sama: Download +18%, Ping −8 ms, dan seterusnya.

📄 Laporan ISP (PDF)

Ringkasan rapi dengan grafik, % dari paket, dan jam-jam lambat. Siap dikirim ke ISP sebagai bukti.

📈 Monitor stabilitas

Ping tiap detik selama 5–30 menit untuk menangkap putus sesaat dan lonjakan lag.

🔄 Update sekali klik

Ada versi baru? Klik Update sekarang, lalu Mulai ulang. Riwayat dan pengaturanmu tetap.

Lambat? Cari tahu penyebabnya

Tab Diagnosa memandu kamu lewat maksimal tiga tes singkat, lalu memberi kesimpulan yang jelas dan tombol ke alat yang tepat, misalnya cek channel Wi-Fi atau laporan ISP. Tidak ada pengaturan router yang diubah.

Temukan posisi Wi-Fi terbaik

Bawa laptop berkeliling. Angka sinyal dan grafiknya bergerak tiap detik, dan bunyinya makin cepat saat sinyal makin kuat. Cocok untuk memilih tempat router atau meja kerja.

Bukti untuk ISP

Semua tes tersimpan di komputermu sendiri, lengkap dengan grafik tren, rata-rata per jenis koneksi, dan % dari paket. Satu klik membuat Laporan ISP dalam PDF.

Cara pakai

  1. Download file zip di atas. Kebanyakan laptop memakai versi x64; pilih ARM hanya untuk laptop Snapdragon.
  2. Ekstrak zip-nya di mana saja, misalnya di Desktop atau flashdisk.
  3. Klik dua kali WiFiSpeedTester.exe. Tidak ada yang perlu diinstal.
Muncul "Windows protected your PC"?

Klik More info → Run anyway (di Windows berbahasa Indonesia: Info selengkapnya → Tetap jalankan). Peringatan SmartScreen ini muncul karena aplikasinya belum punya tanda tangan digital (code signing).

Nama Wi-Fi tidak muncul?

Di Windows 11, nyalakan Settings → Privacy & security → Location → Let desktop apps access your location. Fitur lain tetap jalan tanpa itu.

Butuh apa saja?

Windows 10 atau 11 (64-bit) dengan Microsoft Edge WebView2 Runtime, yang sudah ada di Windows 11 dan kebanyakan Windows 10. Kalau belum ada, aplikasi menawarkan link download-nya.

Privasi

Semua tes berjalan di komputermu. Tidak ada telemetri, tidak ada akun, dan tidak ada yang berjalan di latar belakang. Riwayat tersimpan di folder aplikasi. Hasil yang kamu bagikan (salin hasil, kartu PNG, laporan ISP) tidak memuat nama Wi-Fi atau alamat IP. Daftar lengkap lalu lintas jaringannya ada di dialog Tentang di aplikasi dan di README.
